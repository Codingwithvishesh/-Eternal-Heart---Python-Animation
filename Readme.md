💖 Eternal Heart - Python Animation

An enchanting interactive Python animation created using standard Python libraries (tkinter & turtle). A gold comet traces an outer heart, crimson words sweep in, and a golden inner heart blooms from the center with custom words and a beating rhythm.

"I didn't just write code... I coded a heartbeat for someone special 💖🥰✨"

✨ Features

Gold Comet Outer Heart: Traces the boundaries of a large outer heart.

Dynamic Flying Text: Crimson words in multiple languages sweep in smoothly from outside the screen.

Customizable Inner Heart: Personalize your own words in a golden blooming heart.

Heartbeat Effect: Light rings, upward-drifting embers, and sparkling random glitter once the animation completes.

Zero External Dependencies: Built using Python's standard library (tkinter, turtle, math, random).

🚀 How to Run

1. Prerequisites

Make sure you have Python 3.8 or higher installed on your system.

2. Setup & Execution

Create a new folder on your computer (e.g., HeartAnimation).

Save the script inside that folder as eternal_heart.py.

Open your Terminal or Command Prompt in that folder and run:

python eternal_heart.py


(If python doesn't work, try running python3 eternal_heart.py).

🎨 How to Personalize

Open eternal_heart.py in any text editor or IDE and edit the PERSONALISE block near the top of the file:

# ============================ PERSONALISE ====================================
NAME = "I LOVE YOU"             # Main center text
SIGNATURE = "Forever yours"     # Subtitle text
PERSONAL = (                    # Inner heart custom words
    "You are my home",
    "My favourite person",
    "Always yours",
    "Still choosing you",
    "Thank you",
)
SEED = 11                       # Change number for a different layout
# =============================================================================
